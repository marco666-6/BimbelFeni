4. MODELS & RELASI DATABASE
================================================================================


User (Tabel: users)
--------------------------------------------------------------------------------
  Fillable: username, email, password, role, foto_profil, status

  Relasi: orangTua(), siswa(), notifikasi(), pengumumanDibuat(), tokens(), notifications()


OrangTua (Tabel: orang_tua)
--------------------------------------------------------------------------------
  Fillable: user_id, nama_lengkap, no_telepon, alamat, pekerjaan

  Relasi: user(), siswa(), transaksi(), feedback()


Siswa (Tabel: siswa)
--------------------------------------------------------------------------------
  Fillable: user_id, orangtua_id, nama_lengkap, tanggal_lahir, jenjang, kelas

  Relasi: user(), orangTua(), transaksi(), jadwal(), kehadiran(), pengumpulanTugas(), feedback(), logActivity()


PaketBelajar (Tabel: paket_belajar)
--------------------------------------------------------------------------------
  Fillable: nama_paket, deskripsi, harga, durasi_bulan, jenjang, status

  Relasi: transaksi()


Transaksi (Tabel: transaksi)
--------------------------------------------------------------------------------
  Fillable: kode_transaksi, orangtua_id, siswa_id, paket_id, total_pembayaran, bukti_pembayaran, status_verifikasi, catatan_admin, tanggal_transaksi

  Relasi: orangTua(), siswa(), paketBelajar()


Jadwal (Tabel: jadwal)
--------------------------------------------------------------------------------
  Fillable: siswa_id, mata_pelajaran, nama_guru, hari, jam_mulai, jam_selesai, ruangan

  Relasi: siswa(), kehadiran()


Kehadiran (Tabel: kehadiran)
--------------------------------------------------------------------------------
  Fillable: jadwal_id, siswa_id, status, tanggal_pertemuan, keterangan

  Relasi: jadwal(), siswa()


MateriTugas (Tabel: materi_tugas)
--------------------------------------------------------------------------------
  Fillable: judul, deskripsi, tipe, mata_pelajaran, jenjang, file_path, deadline

  Relasi: pengumpulanTugas()


PengumpulanTugas (Tabel: pengumpulan_tugas)
--------------------------------------------------------------------------------
  Fillable: materi_tugas_id, siswa_id, file_path, tanggal_pengumpulan, nilai, feedback_guru

  Relasi: materiTugas(), siswa()

================================================================================
5. MIDDLEWARE (REQUEST FILTERS)
================================================================================

AdminMiddleware
  • Cek apakah user login
  • Cek apakah role = 'admin'
  • Cek apakah status = 'aktif'
  • Jika tidak memenuhi -> redirect dengan error

OrangTuaMiddleware
  • Cek apakah user login
  • Cek apakah role = 'orangtua'
  • Cek apakah status = 'aktif'
  • Jika tidak memenuhi -> redirect dengan error

SiswaMiddleware
  • Cek apakah user login
  • Cek apakah role = 'siswa'
  • Cek apakah status = 'aktif'
  • Jika tidak memenuhi -> redirect dengan error

CheckActiveSubscription
  • Cek transaksi terakhir yang verified
  • Hitung tanggal berakhir berdasarkan durasi paket
  • Jika sudah expired -> redirect dengan warning

RequestLogger
  • Log semua request ke file txt
  • Catat: user, method, URL, data, response, waktu eksekusi
  • Lokasi: storage/logs/request_tracking/
